## 已定位的链路问题

| 位置 | 当前行为与影响 | 修正方向 |
|---|---|---|
| `remotion/video/LibraryEffects.jsx` → `PresentationText.jsx` | 有 `presentation` 时，逐段出现没有传入分段透明度，渐变没有传入文字 fill；多行文本忽略动态 value。库已选择的动效可在最终排版分支丢失。 | 排版和动效共用文字 run 数据；先固定全文布局，再给 run 施加显现进度。检查单行、多行、中文、公式和数字。 |
| `remotion/shared/presentation-plan.mjs:textPresentation` | 同时抵消相机和节点自身缩放。屏幕字号保护有价值，但也取消有意设计的局部强调。所有文字另统一叠加 0.12 秒淡入淡出。 | 分离世界变换、屏幕字号保护与文字局部强调；只保留一处显隐时钟，不重复淡入。 |
| `remotion/shared/library-compiler.mjs:compileEffects` | 顺序处理效果；路径类会改写整段 frames，后续帧沿用被覆盖属性；同一属性的效果缺少冲突语义。 | 每个属性指定归属与合成顺序；同一通道重叠时明确报冲突或显式合成，不依赖数组顺序。 |
| `remotion/shared/explanation-plan.mjs` 与 `server/motion.schema.json` | 证据只支持位置、缩放、旋转、描线、透明度。纯文字不能作为机制变化，这能防止字幕冒充机制，但无法直接表达真实数值替换或字形重组。库中的遮罩、计数和条形变化也不在同一证据求值路径。 | 区分“信息呈现”和“机制演示”；前者验证真实文字/显现状态，后者继续验证数据、几何与因果。校验与渲染读取同一最终状态。 |
| `remotion/shared/motion-plan.mjs` 与 `library-compiler.mjs` | subject 全程可见；禁止给主体使用 mask 等入场效果。适合完整运输轨迹，却限制图形标题、图片主视觉正常出现和退出。 | 为不同内容定义可见区间与身份交接；关键机制窗口仍强制可见。不用假主体或透明占位绕过。 |
| `remotion/shared/motion-dynamics.mjs`、`video/MotionScene.jsx` | path 的 d 是静态形状；节点内尚无通用路径形变、图片裁切焦点动画、文字 run 变换轨道。 | 先建立能力表；新增能力需 schema、采样器、渲染、检查和导出同步支持。普通 PNG 淡化不声称为形变。 |
| `remotion/server/performance-skill.mjs` | 当前只拼接 SKILL.md 和 frameboard-contract.md；任意新 reference 不会因为存在链接就自动进入下游提示词。 | 关键决策保留在实际加载的入口；实施后按任务加载所需资料，并把资料摘要纳入指纹。 |

以上不能全部归为“缺少效果”。根因是设计意图、素材能力、状态模型、效果编译、排版与验收没有完整对齐。单纯多装 skill 无法修复渲染分支。

## 接入计划：在批准后修改工作台

本节是具体实施范围；尚未修改 `remotion` 源码、运行项目、审核状态或依赖。当地 `remotion/AGENTS.md` 要求先提交计划并获得明确确认。

1. **先修已存在效果的执行。** 修改 `video/LibraryEffects.jsx`、`video/PresentationText.jsx`、`shared/presentation-plan.mjs`，复用原字体测量、注意力层级、draw 和库参数。把文字 run 的 layout、reveal、fill 与 emphasis 分开；默认屏幕文字大小保持，主动文字缩放单独生效。新增真实渲染回归，覆盖多行逐字/逐段、渐变及计数。
2. **补全可执行的动效状态。** 在 `shared` 增加确定性图文状态求值器，接入 `MotionScene`、`motion-dynamics`、`library-compiler` 和相应 schema。显现/退场、强调、几何/内容变换、布局与相机分别建通道；每个属性都有初态、终态、锚点、时间窗与完成后的行为。先支持当前真实需求中的遮罩、局部缩放、图形拆合与同构路径形变；复杂拓扑和照片语义变形明确不承诺。
3. **对齐生成与验收。** 修改 `server/performance-skill.mjs`、`server/auto-motion.mjs`、`shared/auto-motion.mjs`、`shared/explanation-plan.mjs`、`shared/motion-plan.mjs` 及相关 schema/导出文件清单。按信息意图选效果，按同一状态求值检查，保留因果与主体连续性限制；以生命周期窗口替代一刀切的主体常亮。不得通过降低门槛掩盖坏动画。
4. **验证向后兼容及视觉结果。** 老项目无新字段时保持旧解释；保存重开、素材替换、导出工程、乱序渲染、多个帧率均验证。用已获授权的图片、已有录音和图形制作隔离短对照，交付同版关键帧、可播放预览、SRT与正常速度审片记录；不自动宣称正式影片改善或替用户通过审核。

预计新增服务费：0；复用本机工具与已有素材。若具体样片需要新付费素材或配音，先另列请求，不把上述计划视为支付授权。实施结果记录于 `remotion/PROJECT_LOG.md`。

## 设计与验收用例

| 用例 | 可观察结果 | 不能算通过的替代品 |
|---|---|---|
| 图片出现 → 细节 → 退出 | 揭示边界来自图片自身；细节处才短暂强调；退出向下一焦点交接 | 相机从头到尾无目的推近 |
| 两行文字分语块显现 | 首帧不泄露后文，行位不跳，关键词按真实语音出现，整句有阅读区间 | 只有整块透明度变化、多行提前全显示 |
| 图形建立 → 拆分 → 重组 | 能追踪同一部分去哪，数据比例/连接正确，中间状态可读 | 淡出旧图再淡入无关新图，却声称连续形变 |
| 局部放大再归位 | 明确锚点保持稳定，主体没有被裁，文字清楚，回到匹配布局 | 用相机 zoom 代替一切局部强调 |
| 同画面组合与前后镜交接 | 只有当前主信息引导注意；相关支持可并行，因果依赖按顺序；旧元素退场有去处 | 所有对象统一 delay、统一弹性、统一运动 |

样片制作前再记录：同一图片/文字/图形的稳定 ID，起点—中间状态—终点，相机观察目的，跨镜身份/坐标交接，短注释的必要性。时间必须来自实际录音；研究中的假设时序不能直接当作实测。正常速度连续观看是视觉验收，以上自动用例只负责定位工程问题。
