# 动作设计与验收

历史资料：本工作区新影片按 2026-11-16 最新偏好专注图片、文字和图形，不制作人物行走或拿取动画。当前入口为 [图文动效语法](graphics-motion.md)。下列人物案例只保留作旧工程记录；物体确有开合、连接等机制时可借鉴部件原理。

这份结构用于设计，不是当前 Frameboard 已支持的 JSON schema。所有示例时间均为假设，用实际音频与参考重新定位。

## 把动作拆成能看见的变化

“人物走到货架并取书”需要两类运动：根节点穿过场景，脚、胯、躯干与手臂在人物局部空间中运动。把所有路径放在同一个 transform 下，只实现了第一类。

可用关系表示：`世界姿态 = 主体整体变换 × 父部件变换 × 部件局部变换`。先建立关节中心与父子连接，再画各部件。需要柔性变化时再选择形变；不把刚性剪纸转动冒充完整柔性绑定。

对于拿取动作，书先依附货架，接触后切换为随手运动，切换时保留世界位置。若只是切换父级导致书突然跳到手心，附着实现仍然错误。

## 动作记录

| 项目 | 写到什么程度才够 |
|---|---|
| 主体与动作 | 稳定 actorId；动作是走近、拿取、推开、流入等可观察事件 |
| 能力 | rigid、articulated、deformable、poseSequence 或连续媒体；素材确实能支持 |
| 初始/结果状态 | 能从画面识别的状态，不只写“开始/完成” |
| 触发与时间 | 实际 cueId / 事件 ID；作用时刻与允许时间窗；记录定位精度 |
| 主运动 | 起点、经过、终点；速度节奏或物理规律 |
| 内部变化 | 必要部件和角度/位置/几何状态；或刚体无须内部变化的理由 |
| 约束 | 接触、固定轴、附着、守恒、支撑等与题材有关的关系 |
| 次级动作 | 由主动作引起的跟随、回落或反应；不需要时留空 |
| 相机 | 观察目标区域、目的、到位时刻、事件期间取景、空间交接 |
| 可核验证据 | 对应实际输出节点/素材帧与时间，不能仅填“已实现” |

时间以一个主时钟表达。子片段可使用局部时间，但明确 `globalFrame = shotStartFrame + localFrame`；镜头切换不重置身体动作或背景机制。

## 假设案例

一个 8 秒的粗演练，可组织为：

| 假设时间 | 主事件 | 内部变化和因果 | 相机目的 |
|---|---|---|---|
| 0.00–1.70 | 购物者已在走近货架 | 步幅与前进速度匹配；脚在支撑期不滑；头看向目标 | 中景交代人物、货架、同一本书 |
| 1.70–2.50 | 视线落在价签，身体停稳 | 头先转，胸部轻随；重心落在支撑脚；手仍未拿书 | 需要看清价签时提前调整取景 |
| 2.50–3.30 | 伸手抓书 | 肩、肘、手腕分别变化；3.10 秒假设接触；书此前保持在架上 | 手与书的接触区同时可见 |
| 3.30–4.50 | 抽出书 | 接触后书随手移动；书越过架沿，不能穿过相邻书 | 关键抽出过程取景稳定、可追踪 |
| 4.50–6.00 | 看书并反应 | 视线、头部与持书角度协调；背包等只在有惯性理由时轻随 | 让观众读到相关价格/信息 |
| 6.00–8.00 | 转身离开，过程继续 | 肩胯转向与下一步衔接；同一书仍在手里 | 保留运动方向和前后镜空间线索 |

这不是固定节奏模板。用户偏好紧凑时，删除无信息的停留或合并动作；不靠提高语速、增加切镜或把所有阶段挤成瞬间来缩短。

## 从粗动作到成片的检查

1. 粗造型可读：固定观察位置，静音以正常速度确认观众能分辨动作及因果。失败先改姿态和时机。
2. 曲线与重心：检查关键姿态间的路径和 spacing。自动缓动不会自动补齐接触、支撑或正确中间姿态。
3. 次级动作：只给确有表达价值的部件设计相位差，避免全部同起同停；短动作也可以有内部先后。
4. 美术替换：使用同一主体设计；替换后重查活动部件、关节位置与接触点。
5. 相机和声音：按实际事件与音频检查，加入底部小字幕及必要节点短注释；连续正常速度复看。

## 能自动检查与仍需观看的内容

| 动作类型 | 自动检查候选 | 观看判断 |
|---|---|---|
| 行走 | 父级剔除后的腿部姿态变化、步频与位移关系、支撑足世界坐标漂移 | 重量感、意图、步伐自然程度 |
| 拿取/递交 | 接触点误差、接触前道具未跟随、附着切换无跳变 | 接触是否被看见、反应是否合适 |
| 开合 | 部件绕规定轴转动，开口足够，事件顺序正确 | 力度、节奏、解释是否清楚 |
| 刚体运输 | 连续路径、速度、边界/遮挡与作用关系 | 过程可追踪，无须强加肢体变化 |
| 数值机制 | 值、单位、共同尺度与结果时刻，实际几何与数据一致 | 一眼能否比较，信息负担是否合适 |
| 相机 | 作用时刻的目标范围与屏幕尺寸、可见性、字幕区 | 运动是否分散注意、取景是否有叙事价值 |

容差根据画布、比例、动作类型和镜头目的确定，并在验证中明示。不要用全片统一的“每段必须多少运动量”或“必须几种景别”代替判断。刻意的逐帧风格可以使用阶梯姿态，但接触和身份仍需连续。
