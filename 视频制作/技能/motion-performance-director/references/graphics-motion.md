# 图文动效语法与执行要点

这是设计方法，不是 Frameboard 已支持的 schema 或效果名称。以当前引擎能力映射为准。以下为自拟案例，不冒称来源于某一参考视频。

## 一条可执行设计

重要变化写清：`对象与素材版本 → 目的 → 初态/终态 → 保留的身份或参照 → 变化通道 → 实际语音/事件锚点 → 可读区间 → 退出/交接 → 所需能力 → 验收时刻`。

例如：产品正视图保持纵横比，遮罩露出接口；接口可辨后短注释出现；局部放大围绕接口定位，比较信息保持原尺度；讲到下一部件时注释退场。无需让整张图晃动或让相机持续推近。

## 按内容选动作

| 内容 | 出现 | 强调/缩放 | 转换 | 消失与交接 |
|---|---|---|---|---|
| 图片/截图 | 裁切窗揭示、淡入、从来源位置短移 | 固定焦点放大、短框选、周边弱化 | 匹配位置后换图；真实分层才做局部差速 | 收回裁切窗、退到来源或让位 |
| 标题/词组 | 整语块或逐行出现，先固定全文布局 | 关键词轻量尺寸、字重或颜色变化 | 保留重复文字，替换变化部分；词组移位表达关系 | 交接下一主信息，过期标题不堆积 |
| 数字/单位 | 先建立对象或基线，再呈现值 | 结果落定后短强调，预留最终宽度 | 真实起终值插值，单位保持，几何与读数对应 | 保留比较所需数值，过期输入退出 |
| 线/箭头 | 从真实起点按方向绘出 | 强调关键连接 | 更新端点与关联对象，保持连通关系 | 撤回、断开或淡出，不留无主连线 |
| 面/柱/区域 | 从共同基点增长、遮罩揭示 | 固定尺度突出比较项 | 拆分、合并、填充、同构形变，中间状态可解释 | 并入结果、缩回基点或交接下一状态 |

图片的内部变化可在遮罩、可见区域、局部层和注释关系上，不意味着扭曲照片；文字可在语块和关键词上变化；图形可改变路径、比例和连接。动作不需要同时包含多种属性。

## 四种转换分开设计

1. **几何形变**：对应轮廓、控制点或参数持续变化。不能对任意 path 字符串直接插值。同构路径也检查顶点顺序、自交、凹陷与中间形状。
2. **拆分/组合**：数量或关系变了，每个部分仍有身份和目的地。数据图保留比例、总量或相应计算，不能让块凭空消失。
3. **内容替换**：旧字/旧图与新字/新图按位置匹配后交接，如实称为替换。密集文本交叉淡化避免两段内容重叠难读。
4. **布局重排**：内容不变，位置与分组改变。固定起终布局、锚点和路线，维护邻接元素、连线与注释关系。

MorphSVG、Flip、SplitText 是特定工具的能力名，不能直接输出成 Frameboard 的 effectId。

## 时间与曲线

先定语义关键时刻，再安排准备、变化和结果阅读，不把旁白平均切成等长动画。句级时间标明句级精度，需要关键词时另实听定位。

建立位置、揭示内容和强调结果可合理重叠，结果只在完成条件成立后出现。比较对象可同步变化，原因与结果不能为了流畅而错误并行。

初始调试可在 24 fps 下尝试：短强调/淡化 4–8 帧，简单显现 8–16 帧，关系重组 12–28 帧。**这是本地试调起点，不是专业定律、硬门槛或固定模板**；换帧率按秒换算，最终由声音、距离、尺度和正常速度可读性决定。阅读停留另算。

入场落位通常需要减速，离开可更干脆，画内换位可平滑加减速，均匀流动可线性。使用弹簧时检查超调是否破坏数值、边界与对齐。不把统一弹性、随机延迟和不断微漂当作风格。

## 文字的真实渲染

- 字体加载后测全文，锁定换行、基线和目标框；显现仅改变可见部分，不让每增加一字就重新居中整句。
- 中文按语块优先；确需单字时按字素而非 UTF-16 单元拆分。数字与单位、标点、上下标和公式保持语义组合。
- 数据流：完整文本及布局 → 稳定的行/语块位置 → 显现或替换进度 → 颜色与局部强调 → 最终绘制。排版分支共用此数据，不能统一排版后忽略动效。
- 数字递增不表示存在逐时刻实测数据，避免虚构时间趋势。终值、精度、单位与图形长度一致。
- 标题/关键词可有表现性动效，短注释帮助识别，底部字幕稳定同步，不让三层同时跳跃。

## 锚点、坐标与属性归属

图形基线、图片焦点、文字基线与对象中心是不同锚点。缩放围绕明确锚点；中段也检查包围框、裁切、安全区与连接端点，不只验起终帧。

分离布局位置、局部变化、屏幕文字保护与相机。相机不重复放大局部强调；文字保护不取消主动强调。父子层可同时变化，但须有分工，不以两次入场拖延同一信息。

同一节点的 opacity、scale、遮罩和几何各有通道归属。重叠效果明确相乘、替换、叠加或冲突，不靠最后写入者偶然取胜。完成后明确保持、恢复或退出，避免跳回旧关键帧。

离线影片状态应是确定的 `state(frame, fps, design, events)`，同帧首次、回放、乱序计算得到相同结果。借用 GSAP 可编译为原生轨道，或暂停时间线后按帧 seek 并验证初态与布局；不能混入实时 ticker、CSS 播放时钟或未固定随机状态。

## 风格统一与验收

本片约定保持精简：图片处理/裁切、字体层级、描边圆角、色彩角色、光影材质、方向、缓动族和交接关系。复用素材版本和身份。“科技风”或相同 styleId 不等于统一。照片与矢量可共存，明确事实素材、示意与装饰的用途。

先看固定构图的粗版是否讲清，再替换正式图文，最后加必要镜头、声音与短注释。跨镜并排检查外观，连续片段检查比例、位置、方向和时间，正常速度复看并记版本与时间码。

自动检查：显现前不泄露后文、结果有阅读窗口、锚点不漂、数据图形正确、文字无重排/重影、关键事件可见、退出无残影、跨镜不瞬移。视觉检查：注意力实际去了哪里、语块能否一遍读懂、变化是否表达含义、镜头是否帮助观察。

不得以运动量阈值、每镜效果配额或所有对象都动作为审美标准。有目的的整体移动、克制淡入和静止阅读都可以是正确设计。
