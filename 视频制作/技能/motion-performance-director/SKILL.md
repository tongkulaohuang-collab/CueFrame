# 图片、文字与图形动效导演

把观众此刻要理解的变化落实为可见状态、时机和注意力交接，再选择效果。表现丰富来自内容与编排，不以属性数量、运动量或效果种类评分。

本工作区专注图片、文字、图形的出现、消失、转化、放大缩小和组合。人物仅作静态图片或简单符号，不制作走路、摆臂、拿取或表情动画。静态图片可被揭示、裁切、定位和强调；不凭一张图声称拥有内部动作或三维深度。

## 范围与输入

实际读取工作区视频约束和本次制作单。研究、技能修订、引擎修复和影片制作分别说明交付，不为研究擅自制作影片。制作时先有精简台词与真实声音，再使用完整参考分析、现行动效库及参数；复用有效的素材身份、语音锚点与机制契约。按用户授权和项目要求实施。

先定位缺陷层：信息目的、素材能力、时序编排、渲染实现、最终视觉。效果已选但最终渲染没执行，是工程问题；风格不一是素材与设计问题。不要都归咎于提示词。

## 1　用状态变化写动作

每个重要对象写清：稳定身份、要看懂什么、初态与终态、变化通道、发生时机、稳定阅读区间、如何退出或交给下一对象。写“遮罩露出接口，接口可辨后出现标注”，不要只写“高级入场”。

| 信息目的 | 合适的动作方向 |
|---|---|
| 引入 | 淡入、遮罩、描线、短距离落位，方向与来源或阅读一致 |
| 强调 | 局部缩放、颜色或对比变化、短暂标记，保留比较参照 |
| 关系 | 连线、对齐、分组、拆分、合并，改变关系本身 |
| 状态转换 | 对应部件连续变换、数值更新或对位替换，明确保留项 |
| 结束与交接 | 退出、弱化或接入下一对象，过期内容不永久堆积 |

整体位移在重新定位、排序、运输时可以是完整动作。解释填充、比例、拆合、形变时，需要遮罩、数值、局部几何或连接真正改变；整图晃动不能代替它。形变、淡化换图和遮罩替换按真实实现命名。

具体选型见 [图文动效语法](references/graphics-motion.md)。

## 2　用事件安排时间

以实际语音或已确认视觉事件为锚点，分别定位开始变化、语义作用/结果出现、稳定可读与退出。准备可提前，结果不能先于原因完成。按内容选所需阶段，不强制每个动作都走同一套仪式。

记录 cueId、时间窗和定位精度；句级时间不能冒充词级。用事件依赖和相对偏移编排，不在各处独立填写 delay。BGM 辅助强调，不破坏解说因果，也不给配音硬插停顿。

同一信息组可同步；阅读顺序或因果需要时才有先后。交接允许合理重叠，阅读阶段减少无关动作。按内容、距离和尺度调时长，不机械逐字、不统一延迟，不套网页短时长为影片规则。标题和关键词可动，底部字幕保持稳定同步。

## 3　把素材拆到需要控制的层

- 图片：内容、裁切窗口、边框/阴影和注释分开；真实分层才做前后景差速。保持合理纵横比、指定焦点与关键细节。
- 文字：先测完整内容、固定行位，再按语块、行或必要单字显现；数字、单位与标点保持语义组合。计数预留最终宽度。布局、显现、颜色、局部强调共同生效。
- 图形：按数据项、部件、路径或连接拆分，保持基点与对应关系；柱形从共同基线增长，箭头有方向，形变的中间状态有含义。真实机制优先于弹性和趣味。

分离布局定位、内容变化、显隐、局部强调与相机。每个属性有明确归属，重叠时显式合成或报冲突。屏幕字号保护不能把主动文字强调抵消。最终渲染、边界/遮挡检查和机制证据读取同一个合成状态。

## 4　统一美术与运动语言

复用对象 ID、素材版本、裁切基准、颜色角色、字体层级、描边、圆角、光影与透视规则。照片和矢量可共存，但要有明确用途和容器处理。不能只凭同一个 styleId 宣称统一。

复用入场、退出、强调和转换的速度风格及方向习惯，再按对象尺度与信息难度调整。次级动作须有表达价值，不凭空给科学对象增加形变、情绪或反弹。美术替换后重查实际图像边界、换行、遮罩和中间状态；草稿正确不代表最终素材正确。

## 5　镜头服务观察任务

先判断固定构图能否讲清。需要推近、拉远或跟随时写清：要看哪个细节或关系、当前看不清什么、何时到位、保留什么空间参照。局部对象缩放和相机缩放分开选择；比例、对比与形变过程中尽量保持比较尺度稳定。

关键变化到来时目标应已可见，镜头不能导致主体、字幕与注释互相遮挡。跨镜延续同一身份、方向、状态和时间；出现或消失也有去向和接续。焦点 ID 与文字理由只证明有计划，仍需看实际输出。

## 6　验证执行，再判断效果

先选一个最难的交接片段，用粗素材验证信息与时间，再替换正式素材并润色，最后推广整片。区分能力、事件、最终帧与正常速度连续观看四类证据；记录版本、时间码、问题、修正和复看范围。

工程检查覆盖真实排版/素材分支、初末状态、阅读窗口、遮挡、跨镜接续、保存重开和乱序帧。所有状态由同一帧时钟重建，不依赖墙钟、播放顺序或未固定随机数。机制如有接触、开合或附着，仍核对真实连接与事件顺序。

连续正常速度观看判断节奏与可读性；静帧仅验构图，运动量和非空说明不能证明质量。默认底部小号同步字幕并交 SRT，关键节点加贴近对象的短注释，不重复整段解说。未实际播放或未听到音轨如实标明，不冒充导演/听审通过。

## 工具与能力路由

- 筛选工具时读 [专业来源与技能](references/sources-and-skills.md)。GSAP 提供编排和文字/SVG能力参考；Remotion负责帧驱动。Emil 的编排经验按影片需要改用，不照搬 UI 硬规则。
- Frameboard 任务读 [运行契约](references/frameboard-contract.md)。设计表不是可提交的 JSON；未实现的效果提出范围或诚实降级，不伪造组件与参数。
- 修工作台时读 [图文诊断与接入记录](references/graphics-engine-plan-2026-11-16.md)，核对其历史诊断与实际完成状态；当前能力以运行契约、schema 和回归结果为准。
- [旧部件动作记录](references/action-design.md) 与 [旧对象表演诊断](references/frameboard-plan-2026-11-16.md) 供历史工程或确有开合等机制的物体查阅，不作为新影片的人物动作模板。
